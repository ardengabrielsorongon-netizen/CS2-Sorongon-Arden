#Travel Fare Calculator

## Description
This program calculates the fare of an amount of passengers given the distance and rate.

# Version 1 - Original code without input validation
Input: Accepts the passenger name, distance to travel, and amount of passengers
Process: Calculates the fare for all persons, adds to one lump sum
Output: Sum of all passenger's fares
Does not include input validation.

# Version 2 - Updated code with input validation
Input: Accepts a non-blank passenger name, a nonzero and non negative distance, and a nonzero and non negative integral amount of passengers.
Process: Calculates the fare for all persons, adds to one lump sum, and gives the name.
Output: Sum of all passenger's fares a with name 
Includes input validation
